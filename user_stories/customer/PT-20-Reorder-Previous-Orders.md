# User story title: Re-order previous order quickly

## Priority: 20
Iteration 2 candidate (Customer convenience).

## Estimation:
TBD (planning poker).

## Assumptions (if any):
- Re-order is available from order history.
- Unavailable items are flagged and can be replaced.

## Description:
Description-v1: As a **customer**, I want to re-order a previous order quickly, so I can repeat favorite meals with less effort.

## Tasks
1. Add re-order action in order history.
2. Copy previous items/options into a new cart.
3. Handle unavailable items and pricing changes.

# UI Design:
