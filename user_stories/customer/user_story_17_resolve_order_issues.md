# User story title: Resolve order issues

## Priority: 20
Iteration 2/3 candidate (Customer support flow).

## Estimation:
TBD (planning poker).

## Assumptions (if any):
- Customer can raise an issue against a placed order.
- Issue categories include missing item, delay, wrong order, and refund request.

## Description:
Description-v1: As a **customer**, I want to resolve order issues quickly, so I can get support, refunds, or corrections when problems happen.

## Tasks
1. Add issue reporting for completed/active orders.
2. Create issue status tracking and updates.
3. Link issue outcomes to refund/support workflows.

# UI Design:
- Order issue form with status timeline.
