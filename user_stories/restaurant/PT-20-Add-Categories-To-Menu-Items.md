# User story title: Add categories to menu items

## Priority: 20
Supporting feature (Menu organization).

## Estimation:
TBD (planning poker).

## Assumptions (if any):
- Restaurants can create and reuse categories (e.g., mains, drinks, desserts).
- One menu item can belong to at least one category.

## Description:
Description-v1: As a **restaurant**, I want to add categories to menu items, so customers can browse my menu more easily.

## Tasks
1. Add category create/edit controls in menu management.
2. Allow assigning categories when adding/editing items.
3. Display grouped categories on customer-facing menu pages.

# UI Design:
- Category manager and category selector in add/edit item form.
