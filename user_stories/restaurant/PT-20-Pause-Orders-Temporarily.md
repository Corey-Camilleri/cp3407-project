# User story title: Pause orders temporarily

## Priority: 20
Iteration 2 candidate (Restaurant operations).

## Estimation:
TBD (planning poker).

## Assumptions (if any):
- Restaurant can pause ordering for short periods (busy/offline).
- Customers see clear unavailable messaging while paused.

## Description:
Description-v1: As a **restaurant**, I want to pause incoming orders temporarily, so I can manage kitchen load during peak periods.

## Tasks
1. Add pause/resume toggle in restaurant dashboard.
2. Block new checkout submissions while paused.
3. Display pause status on restaurant listing/menu pages.

# UI Design:
- Availability switch with pause reason and estimated resume time.
